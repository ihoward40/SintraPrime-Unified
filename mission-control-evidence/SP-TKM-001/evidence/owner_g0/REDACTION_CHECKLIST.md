# G-0 Evidence Redaction Checklist

For every screenshot submitted by the owner, confirm the following:

## Must Be Hidden/Blurred

- [ ] Legal name
- [ ] Date of birth
- [ ] Tax numbers or tax identifiers
- [ ] Payout details, bank account numbers, card numbers
- [ ] Home address or personal location
- [ ] Recovery codes, QR codes, backup codes
- [ ] Authentication tokens, session cookies, API keys
- [ ] Phone numbers
- [ ] Unredacted identity documents

## Must Remain Visible Where Applicable

- [ ] Feature name or menu path
- [ ] Eligibility result or status
- [ ] Account standing or health status
- [ ] Follower count
- [ ] View count and date range
- [ ] Warning category or restriction type
- [ ] Region, country, or availability status
- [ ] Screenshot date
