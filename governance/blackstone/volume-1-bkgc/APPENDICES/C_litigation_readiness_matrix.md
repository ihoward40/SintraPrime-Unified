# Appendix C — Litigation Readiness Matrix (Informative)

## Derived From

BKGC Article IX § 9.2, Article XIII, and Article XIV.

## Readiness Levels

| Level | Description |
|-------|-------------|
| L0 — Internal Draft | Preliminary analysis, not verified |
| L1 — Corroborated | Supported by one or more sources |
| L2 — Verified | Independent reproduction or review completed |
| L3 — Reviewed | Human reviewer approved |
| L4 — Litigation Ready | Chain of custody, provenance, and audit trail complete |

## Requirements for Litigation Ready

- Unique evidence identifiers
- Source provenance preserved
- Counter-evidence identified
- Jurisdiction checked
- Reviewer identity recorded
- Reasoning chain documented
- No unaddressed failure modes

## Downstream Use

BCCM Test Suite includes litigation-readiness checks. BRA implements the readiness lifecycle in the Evidence Engine.
