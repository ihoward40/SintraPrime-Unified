# Registry — Agent Certification

## Authority

This registry records certified agents and implementations.

## Derived From

BCCM § 1, § 6; BKGC Article XXIV.

## Entries

| Cert ID | Name / Implementation | Level | Date | Expiry | CDR |
|---------|----------------------|-------|------|--------|-----|
| | | | | | |

## Rules

1. Only the governance steward may add or revoke entries.
2. Revocation MUST be recorded as a CDR.
3. Renewal entries MUST reference the latest BCCM version.

## Initial State

This registry begins empty. SintraPrime-Unified will be the first candidate for certification once the reference architecture is implemented.
