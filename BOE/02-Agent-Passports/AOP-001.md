# AOP-001 — Agent Operating Passport Standard

## Purpose

Define the minimum identity and accountability contract required for an agent to participate in BOE decision cycles.

## Required Passport Fields

- `passport_id`
- `agent_name`
- `mission_scope`
- `decision_authority`
- `decision_inputs`
- `decision_outputs`
- `operating_constraints`
- `evidence_protocol`
- `owner`
- `status`

## Operating Rules

1. No agent may execute a BOE decision function without a completed passport.
2. Passport authority must be explicit and bounded.
3. Evidence protocol must identify how each recommendation is substantiated.
4. Status must be `active` for Sprint 1 operations.
