# DRS-001 — Decision Register Standard

## Purpose

Define the minimum standard for recording executive decisions so each decision is durable, auditable, and evidence-linked.

## Required Fields

Each decision record MUST include:

- `decision_id` (format: `DR-0001`)
- `decision_title`
- `recorded_on` (ISO date)
- `status` (`proposed`, `active`, `superseded`)
- `decision_owner`
- `decision_summary`
- `evidence`
- `execution_items`
- `review_date`

## Operating Rules

1. The register is append-only.
2. A decision is operational when status is `active`.
3. Each evidence reference must identify source material and date.
4. Superseding a decision requires a new `decision_id`.

## Storage

- Canonical schema: `Decision_Register.schema.json`
- Canonical records: `Decision_Register.jsonl`
