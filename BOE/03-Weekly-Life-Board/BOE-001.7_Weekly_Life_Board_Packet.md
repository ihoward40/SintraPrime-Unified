# BOE-001.7 — Weekly Life Board Packet

## 1. Purpose

Define the standard weekly packet used by the Life Board to run repeatable, evidence-based decision cycles.

## 2. Packet Metadata (Required)

- **Packet ID:** `WLB-YYYY-WW` (ISO week format)
- **Board Date:** `YYYY-MM-DD`
- **Prepared By:** owner/agent name
- **Decision Window:** start/end dates covered by the packet
- **Related Decision Register Entries:** DR IDs referenced in this packet

## 3. Standard Packet Order (Required)

1. Executive Summary
2. Decisions
3. Confidence Updates
4. Risks
5. Opportunities
6. Reviews

## 4. Section Requirements

### 4.1 Executive Summary

- 3-7 bullets covering the week in plain language
- Current institutional posture: `Stable | Watch | Corrective`
- Key movement since last packet (what changed and why)
- If there are no material changes, use a single bullet: `No updates this cycle`

### 4.2 Decisions

For each decision:

- Decision title
- Decision type: `New | Reaffirmed | Reversed | Deferred`
- Decision owner
- Decision rationale (evidence-based)
- Linked DR entry ID (or `Pending DR`)
- Execution deadline

### 4.3 Confidence Updates

Track confidence for active priorities on a 0.0-1.0 scale.

For each priority:

- Priority name
- Prior confidence
- Current confidence
- Delta (`current - prior`)
- Evidence driving the update
- Trigger threshold crossed (if any)

### 4.4 Risks

For each risk:

- Risk statement
- Probability: `Low | Medium | High`
- Impact: `Low | Medium | High`
- Early warning signal(s)
- Mitigation owner
- Mitigation status: `Planned | Active | Blocked | Closed`

### 4.5 Opportunities

For each opportunity:

- Opportunity statement
- Expected upside (quantified when possible)
- Cost/effort estimate
- Time sensitivity: `Immediate | Near-term | Long-term`
- Opportunity owner
- Next action and due date

### 4.6 Reviews

Capture structured review outcomes:

- Prior week commitments: met/missed with reason
- Decisions under review (still valid, revise, or retire)
- Open board asks for next cycle
- Required follow-up artifacts and owners

## 6. Completion Rule

A weekly packet is valid only when all required metadata is present and each required section is included, even if a section has an explicit `No updates this cycle` entry.
