# Routing Policy

Routing is policy-driven and provider-neutral. The router evaluates task fit, role fit, sensitivity, cost ceiling, latency class, availability, declared tool support, approved provider allowlists, data policy, and checker-independence exclusions.

Benchmark-only routing is prohibited. Rejected providers must be recorded with reasons. Every selected route records candidate providers, rejected providers, applied policy, selection reason, estimated cost, and actual cost when available.
