# Case — Historical Trust Treatise

## Case ID

BGC-CASE-004

## Title

Historical Trust Treatise

## Scenario

A user asks about the historical origin of a trust provision. A respected 19th-century treatise describes the doctrine, but modern statutes have substantially revised it.

## Inputs

- 19th-century treatise.
- Current trust statute.
- Recent judicial opinion citing the treatise only for historical context.

## Governing Principles and Articles

- BKGC § XI — Temporal Governance
- BKGC-R-010 Stale Authority Flag
- BKC-C-016 Revision
- BGS-S-006 Score Disagreement

## Evidence Evaluation

| Evidence | Source Category | Weight | Temporal Status |
|----------|-----------------|--------|-----------------|
| 19th-century treatise | Scholarly / Historical | Historical | Superseded by modern legislation |
| Current trust statute | Government Publication | Controlling | Current |
| Recent judicial opinion | Judicial Decision | Persuasive | Uses treatise only for historical context |

## Reasoning

1. The historical treatise accurately reflects the doctrine as it existed when written.
2. Modern legislation has revised the doctrine, so the treatise is no longer controlling.
3. The treatise remains valid as historical evidence and may explain the original purpose of current statutory language.
4. The recent opinion models correct usage by limiting the treatise to historical context.

## Outcome

- Cite the current statute as controlling authority.
- Cite the treatise only for historical background.
- Flag the treatise as historical, not current.
- Preserve the treatise because later interpretive disputes may require understanding the doctrine's origin.

- Temporal status must be explicit to prevent stale authority reliance.
