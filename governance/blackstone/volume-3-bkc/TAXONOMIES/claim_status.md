# Taxonomy — Claim Status

## Derived From

BKGC Article XV § 15.1, BGS 5.

## Statuses

| Status | Code | Definition |
|--------|------|------------|
| Controlling | CONTROLLING | Supported by governing legal authority within the relevant jurisdiction. |
| Persuasive | PERSUASIVE | Supported by respected but non-controlling authority. |
| Historically Documented | HISTORICAL | Supported by historical evidence but not necessarily current law. |
| Scholarly | SCHOLARLY | Derived primarily from academic analysis. |
| Educational | EDUCATIONAL | Intended for learning and explanation. |
| Emerging | EMERGING | Supported by limited evidence requiring validation. |
| Disputed | DISPUTED | Credible authorities materially disagree. |
| Unverified | UNVERIFIED | Insufficient evidence currently available. |

## Rules

1. A claim MUST carry exactly one status.
2. Status MUST be derived from evidence quality, not author confidence.
3. Status MUST be downgraded when counter-evidence is material.
4. A disputed claim MUST preserve competing positions.
