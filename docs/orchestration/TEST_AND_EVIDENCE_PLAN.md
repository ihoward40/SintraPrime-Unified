# Test And Evidence Plan

Milestone One certification requires backend unit and integration tests for classification, decomposition, role assignment, routing, budget enforcement, retries, cancellation, reconciliation, confidence, redaction, approval gates, audit records, plan and execute endpoints, event retrieval, partial completion, and high-assurance flow.

Frontend certification requires type-check, build, Command Center route checks, Operations Floor integration checks, mobile rendering, no horizontal overflow, and inspected screenshots.

Evidence must record exact commands, pass/fail status, screenshot paths, and any residual blocker. No external provider, paid API, deployment, merge, or external action may be performed during certification.
