# SP-TKM-001 Evidence Repository

This directory holds verification evidence for every gate and milestone in Mission SP-TKM-001.

## Folder Layout

- `gate_checklists/` — Completed checklists for gates G-0 through G-9.
- `screenshots/` — Account eligibility screenshots, TikTok Studio captures, published-video screenshots, and dashboard snapshots.
- `urls/` — Text files containing published video URLs, LIVE URLs, landing-page URLs, and affiliate/sponsor links.
- `verification/` — Test results, checkout receipts, email captures, and any third-party platform evidence.

## Naming Conventions

- Gate checklists: `GATE_<number>_CHECKLIST.md`
- Screenshots: `YYYYMMDD_<subject>_<optional-sequence>.png`
- URL lists: `YYYYMMDD_<subject>_URLS.md`
- Verification files: `YYYYMMDD_<subject>_EVIDENCE.md`

## Evidence Standard

Every claim of completion must link to at least one artifact in this directory. No fabricated screenshots, URLs, metrics, customers, eligibility, sales, or completion claims are permitted.
