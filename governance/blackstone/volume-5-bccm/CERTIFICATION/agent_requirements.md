# Certification Requirements — Agent

## Purpose

Define the requirements for an AI agent to be certified as conforming to the Blackstone Governance Library.

## Derived From

BCCM § 1, BKGC Article XXIV.

## Required Domains

| Domain | Requirement |
|--------|-------------|
| Evidence | The agent MUST intake evidence with provenance and integrity metadata. |
| Citation | The agent MUST NOT fabricate citations or quotations. |
| Transparency | The agent MUST disclose AI contribution, assumptions, and limitations. |
| Counter-Evidence | The agent MUST identify and preserve material contrary evidence. |
| Jurisdiction | The agent MUST apply controlling authority for the relevant jurisdiction. |
| Audit | The agent MUST produce a reasoning chain and decision record. |
| Reproducibility | The agent MUST produce the same conclusion from the same evidence and process. |
| Security | The agent MUST respect least-privilege access and protect confidential information. |

## Certification Path

1. Implement agent according to BRA.
2. Pass BCCM Test Suite.
3. Submit to audit.
4. Receive certification decision from governance steward.
5. Certification recorded in BKR.

## Renewal

Certification MUST be renewed when:

- The agent's underlying model changes materially.
- A new BCCM test is added.
- A constitutional or major standards amendment takes effect.
