# Federal Foundation

Phase 2C-1 establishes the reusable federal authority layer in `data/federal/` using the existing `LegalAuthority`, `JurisdictionRule`, `ConflictRecord`, review, challenge, and audit schemas.

The package contains 15 authority records and 12 issue-spotting rules covering bankruptcy, FDCPA, FCRA, TILA/FCBA, EFTA, ECOA, federal benefits, federal tax, SCRA, arbitration/evidence preservation, and federal intersections with state UCC analysis.

Rules retain citation, issuing body, source classification, verification state, effective date where known, provenance links, limitations, and human-review requirements. No rule is production eligible.
