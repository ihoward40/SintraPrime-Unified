# Provider Contract

Milestone One providers are deterministic mocks only: `reasoning_model`, `coding_model`, `research_model`, `checker_model`, and `security_model`.

Providers must declare capabilities before routing: supported task types, context window, structured output, tool support, task strengths, latency class, zero mock cost, availability, data policy, allowed sensitivity, enabled state, and confidence history.

No external provider, paid API, credential, session cookie, or live model endpoint is connected in Milestone One.
